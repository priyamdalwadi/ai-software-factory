# Roadmap

1. Fresh full-stack website: create/complete/filter/search/delete tasks, database persistence, responsive frontend, automated API tests. Publish to the existing repository after verification.
2. PR exercise: make a small page change; inspect CI; deliberately demonstrate a failure on an unmerged branch and repair it.
3. Enforced gates: require CI and appropriate human reviews; require an up-to-date target branch; explain conflicts and queue alternatives.
4. GCP setup: user completes sign-in/billing; review IAM, budget alerts, proposed resource costs, and access controls before provisioning.
5. Deployment: container image, Artifact Registry, Workload Identity Federation, managed persistence, Cloud Run staging, smoke tests.
6. Production: human approval, immutable build promotion, rollout verification, rollback and logs.

No agents or autonomous production releases are part of the current milestone.
